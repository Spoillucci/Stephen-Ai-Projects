# Email Management Dashboard Hub

This repository contains a responsive dashboard that acts as a central hub for an email management workflow.

## Included

- **Overview metrics** (unread, due today, response time, active automations)
- **Priority queue** with search and due-date filters
- **Mailbox health** progress cards
- **Automation center** status list
- **Quick compose** form to queue drafts
- **Recent activity** timeline feed

## Run locally

Because this is a static frontend, you can open `index.html` directly in a browser or serve it with a simple local server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.
